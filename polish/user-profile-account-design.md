# 第四步：用户主页与账号管理功能设计

> 本文档用于详细拆解第四步要实现的用户主页、用户资料和账号管理能力。`docs/progress.md` 只保留当前进度概览，具体功能细节在本文维护。

## 目标

- 将用户主页从基础统计页升级为完整个人主页。
- 支持用户查看作品、喜欢、粉丝和关注列表。
- 支持登录用户管理自己的基础资料和账号安全信息。
- 保持功能范围适合面试项目，不提前引入复杂后台系统。

## 功能范围

### 1. 前端主页展示

- [x] 顶部资料区只显示用户头像入口，删除原有 `Feed`、`发布`、`登录` 文本导航。
- [x] 已登录用户点击头像跳转自己的用户主页：`/users/{currentUserId}`。
- [x] 未登录用户点击默认头像入口跳转登录页：`/login`。
- [x] 前端启动时使用 `GET /api/v1/users/me` 恢复当前用户资料，用于展示头像和判断跳转目标。
- [x] 顶部资料区展示字段：只展示圆形头像；没有头像时展示昵称或用户名首字母。
- [x] 当前步骤不新增后端接口，复用已有 `GET /api/v1/users/me`。
- [x] 主页左侧功能栏的“账号”改为“主页”，点击后已登录跳转用户主页，未登录跳转登录页。
- [x] 左侧功能栏已上移到全局 `App.vue`，所有页面都会显示，并在桌面端固定在左侧。
